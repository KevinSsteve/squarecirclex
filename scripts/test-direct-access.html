🧪 Test Direct Access

⚠️ Importante: Antes de testar, certifique-se de que:
  • Você está autenticado (fez login)
  • O servidor de desenvolvimento está rodando
  • Você limpou o localStorage (se necessário)

Teste 1: Acesso Normal

Tenta acessar /app normalmente

Teste 2: Com Parâmetro ?view=game

Força o modo game através do parâmetro URL

Teste 3: Limpar e Acessar

Limpa viewToggle e acessa /app

Teste 4: Forçar Game Mode

Define viewToggle como 'game' e acessa

💡 Dica: Abra o DevTools (F12) e vá para a aba Console para ver os logs de redirecionamento.

Procure por mensagens como:
  • [GameView] User prefers traditional view - redirecting to dashboard
  • [GameView] Game view not available - redirecting to dashboard
  • [ViewToggle] View changed: ...
